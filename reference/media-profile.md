# 样例媒体配置

本文件整理当前 workspace 使用的媒体导出规则，供 agent 直接执行。官方规格摘录见 [minimax-h3/input-specs.md](minimax-h3/input-specs.md)。

## 默认配置

| 项目 | 当前 workspace 的约定 |
| --- | --- |
| 目标时长 | 默认 5–15 秒，并按对齐后的帧数检查 |
| 帧率 | 24 FPS（frames per second，每秒帧数） |
| 帧数 | 视频采用 `N = 17 × k + 5`，同时满足长度限制 |
| 目标横屏画布 | 样例为 1344 × 768；宽高均是 32 的倍数 |
| 其他画幅 | 参考实现以短边 768、像素面积预算 `768 × 1344` 求取画布，再对齐到 32；保持内容原比例，必要时补边 |
| 目标声音 | 32000 Hz，双声道 |
| 目标训练波形 | WAV（Waveform Audio File Format），16-bit PCM（pulse-code modulation） |
| 每声道采样数 | `round(N / 24 × 32000)` |

**时长差异**：随附 H3 官方指南允许 4–15 秒，样例适配的本地实现采用 5–15 秒。本 workspace 保留二者的兼容范围 5–15 秒。以后切换实际训练或推理实现时，应重新确认要求，而不是把本地限制称为 H3 的统一官方限制。

例如，目标 175 帧满足 `17 × 10 + 5`，时长为 `175/24` 秒，对应每声道 233333 个采样点。不能先以未对齐时长通过检查，再把帧数向上补到超过 15 秒。

导出时预先让参考视频也满足 `17n+5`，是为了避免编码器再次截去部分末尾内容。所选原始片段的语义边界和导出后时长仍需分别核对。

## 样例处理方式

原片为 1280 × 720、`24000/1001` FPS。样例先精确裁切，再转为 24 FPS；画面等比缩放至 1344 × 756，上下各补 6 像素。参考视频与目标末尾分别补约 0.119 秒、0.034 秒，只重复所选区间末帧并为声音补静音，没有读取下一镜头。

目标 WAV 直接从原片目标区间提取并重采样。WAV 的采样格式和最小输出目录是本地数据约定；这些约定与模型内部音频表示不是同一个层次。

H3 指南的快照来源、哈希见 [SOURCES.json](SOURCES.json)。样例实际媒体参数及来源区间见 [provenance.json](../examples/evidence/provenance.json)。
